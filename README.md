# Налоговый оптимизатор портфеля — AI-агент на T-Invest MCP

Заявка на программу **«Инвест. Премаркет»** (Т-Банк), направление **«AI-агент»**.

AI-агент круглый год следит за брокерским портфелем клиента и ищет способы
законно снизить НДФЛ, который брокер удержит по итогам года. Для этого агент
фиксирует бумажные убытки (*tax-loss harvesting*) и заменяет проданную бумагу
аналогом с той же дюрацией, доходностью и риском. Состав портфеля по сути
не меняется, а налог к удержанию снижается.

> Статус: прототип для этапа SIGNAL IN. Ядро расчётов работает и покрыто тестами,
> данные синтетические. Подключение к T-Invest MCP запланировано на этап SYSTEM BUILD.

## Проблема

* С 2025 года инвестиционный доход свыше **2,4 млн ₽** в год облагается
  по ставке **15%** вместо 13%.
* Брокер — налоговый агент: он удерживает НДФЛ в конце года или при выводе денег.
  Особенно это заметно у тех, кто получает купоны на брокерский счёт, а не на карту.
* Убыток по ценным бумагам уменьшает налоговую базу (прибыль от сделок и купоны)
  в том же году. Но зафиксировать его выгодно только с учётом размера базы,
  ставки, комиссий, льготы долгосрочного владения и FIFO-списания.
* Сейчас инвестор делает это вручную по отчёту брокера в Excel, обычно в последние
  дни декабря, или не делает вовсе. Готового инструмента у российских брокеров нет.

## Решение

```
Портфель и операции (T-Invest MCP)
        │
        ▼
Налоговый движок ── база по ЦБ с купонами, НДФЛ 13/15%, FIFO, льгота 3 года
        │
        ▼
Кандидаты ── позиции с бумажным убытком; исключаем лоты рядом с ЛДВ
        │
        ▼
Подбор аналогов ── тип, валюта, квалстатус, риск ≤ исходного,
        │          |Δдюрации| ≤ 0,5 г., |ΔYTM| ≤ 1 п.п., сектор, частота купона
        ▼
Оптимизатор ── максимум (экономия НДФЛ − комиссии − спред), частичная продажа
        │
        ▼
LLM-агент ── проверяет аналоги на соответствие стратегии клиента,
        │    исключает неподходящие, объясняет простым языком
        ▼
Push / чат: «Можно сэкономить 52 585 ₽» → клиент подтверждает → заявки через MCP
```

**Разделение ответственности.** Налог и оптимум считаются детерминированно,
LLM не «угадывает» числа. Агенту поручено то, что плохо формализуется правилами:

* понять неявную стратегию клиента по составу портфеля («ежемесячный купон»,
  «короткие ОФЗ», «дивидендные акции») и отбраковать формально близкий,
  но неподходящий аналог;
* оркестрировать вызовы инструментов и проверять ограничения;
* объяснить рекомендацию и ответить на вопросы («почему не продать Банк А?»).

## Быстрый старт

Нужен Python 3.10 или новее. Ядру не нужны внешние зависимости.

```bash
python -m taxharvest data/portfolios/client_a.json --compare
python -m unittest -v
```

Режим агента (LLM вызывает инструменты сам):

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
python -m taxharvest data/portfolios/client_a.json --agent
```

Модель задаётся переменной `TAXHARVEST_MODEL`. Инструменты агента описаны
в [`taxharvest/agent.py`](taxharvest/agent.py), они провайдер-независимы:
их можно подключить к GigaChat или YandexGPT через тот же интерфейс tool calling.

## Пример результата (клиент A, синтетические данные)

| # | Продать | Убыток | Купить | Экономия | Издержки |
|---|---|---|---|---|---|
| 1 | Нефтяная А | −240 000 ₽ | Нефтяная Б | 36 000 ₽ | 930 ₽ |
| 2 | ОФЗ-А 03.2031 | −90 000 ₽ | ОФЗ-Б 08.2031 | 13 500 ₽ | 1 185 ₽ |
| 3 | Энергосеть К 2029 | −24 000 ₽ | Генерация М 2029 | 3 600 ₽ | 1 275 ₽ |
| 4 | ОФЗ-Г 06.2028 | −36 000 ₽ | ОФЗ-Д 09.2028 | 5 400 ₽ | 2 526 ₽ |

НДФЛ за год снижается с 444 000 ₽ до 385 500 ₽, чистая выгода 52 585 ₽.
Дюрация облигаций 2,15 → 2,40 года, YTM 13,95 → 13,62%.
Позицию «Банк А» агент не трогает: лоту 2,7 года, и продажа обнулит срок
для льготы долгосрочного владения.

Полный вывод по трём клиентам: [`docs/demo-output.md`](docs/demo-output.md).

| Клиент | Ситуация | Агент | Правило «продать все убыточные и откупить» |
|---|---|---|---|
| A | база 3,1 млн ₽, ставка 15% | +52 585 ₽ | +63 391 ₽*, но продаёт лот рядом с ЛДВ |
| B | убытков больше базы, квал | +32 607 ₽ (частичная продажа) | +27 180 ₽ (лишние издержки) |
| C | прибыли за год нет | клиента не беспокоит | −1 144 ₽ (сделки без смысла) |

\* Правило выигрывает в этом году за счёт продажи «Банк А», но клиент теряет шанс
на освобождение будущей прибыли по льготе 3 года. Агент выносит такие случаи
в раздел «Не трогаем», и решение остаётся за клиентом.

## Структура репозитория

```
taxharvest/
  models.py     модели: бумага, лот, портфель, настройки
  bonds.py      график купонов, НКД, YTM, дюрация Маколея
  tax.py        НДФЛ 13/15%, налоговая база, FIFO, ЛДВ
  analogs.py    подбор аналогов и метрика близости
  optimizer.py  выбор сделок, эталонный перебор, базовое правило
  agent.py      инструменты агента, системный промпт, цикл tool use
  sources.py    источники данных: JSON-sandbox и адаптер T-Invest MCP
  report.py     отчёт для клиента
data/           синтетический справочник бумаг и портфели
docs/           архитектура, налоговые правила, план эксперимента
tests/          unit-тесты (15)
```

## Ограничения прототипа

* Данные синтетические: тикеры, эмитенты и цены вымышлены.
* Налоговую базу и финрез клиента T-Invest API напрямую, скорее всего,
  не отдаёт. Восстанавливаем их по операциям и сверяем с отчётом брокера.
* Не рассматриваются: ИИС, ПФИ, валютная переоценка, перенос убытков прошлых лет
  (он возможен только через декларацию), НКД при продаже.
* Рекомендации подаются как информация о налоговых последствиях. Решение принимает
  клиент. Регуляторный формат обсудим с Т-Банком.
