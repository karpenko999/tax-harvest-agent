# Как проверяем, что решение работает

## Гипотеза

Агент находит экономию НДФЛ, близкую к максимально возможной, не меняет
характеристик портфеля и не нарушает ограничений: квалстатус, льгота 3 года,
риск не выше исходного.

## Данные

* 50 синтетических портфелей в sandbox: акции, ОФЗ, корпоративные облигации;
  разные сочетания прибыли и убытков; квал и неквал; лоты рядом с ЛДВ.
  Сейчас в `data/portfolios` лежат 3 портфеля, генератор остальных — следующий шаг.
* 5–10 обезличенных портфелей участников команды.

## С чем сравниваем

1. **Базовое правило:** «в декабре продать все убыточные позиции и откупить их же»
   (`optimizer.naive_plan`).
2. **Эталон:** полный перебор подмножеств позиций (`optimizer.brute_force`).
3. **Эксперт:** ручной подбор замены инвестиционным консультантом (на этапе пилота).

## Метрики и пороги

| Метрика | Порог |
|---|---|
| Чистая экономия (НДФЛ − издержки) от эталона | ≥ 90% |
| Отклонение дюрации облигационной части | ≤ 0,25 года |
| Отклонение YTM облигационной части | ≤ 0,5 п.п. |
| Нарушения ограничений (квал, ЛДВ, риск) | 0 |
| Рекомендации, которые эксперт признал приемлемыми | ≥ 80% |
| Клиенты без выгоды, которых побеспокоили | 0 |

## Что уже проверено (unit-тесты)

* Прогрессивная ставка, дивиденды не уменьшаются убытками, FIFO с ЛДВ.
* YTM облигации по номиналу равна купону, дюрация меньше срока до погашения.
* Бумаги «для квалов» не предлагаются неквалам, аналог не рискованнее исходной бумаги.
* Жадный оптимизатор даёт не меньше 90% от полного перебора на всех портфелях.
* При малой базе агент обгоняет базовое правило за счёт частичной продажи.
* Клиента без прибыли агент не беспокоит.
