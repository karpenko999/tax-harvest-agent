# Архитектура

## Компоненты MVP

| Компонент | Что делает | Технологии |
|---|---|---|
| Агент-оркестратор | вызывает инструменты, проверяет аналоги на соответствие стратегии, объясняет | LLM с tool calling (Claude / GigaChat / YandexGPT) |
| T-Invest MCP | портфель, операции, справочник, купоны, цены, заявки | MCP-сервер Т-Инвестиций, в MVP — sandbox, только чтение |
| Налоговый движок | база по видам дохода, FIFO, ЛДВ, НДФЛ 13/15% | Python, `taxharvest/tax.py` |
| Подбор аналогов | фильтры и метрика близости, YTM и дюрация по графику купонов | `taxharvest/analogs.py`, `bonds.py` |
| Оптимизатор | максимум экономии за вычетом издержек, частичная продажа | `taxharvest/optimizer.py`; в продакшене MILP (OR-Tools) |
| RAG | нормы НК РФ (ст. 214.1, 219.1, 224), регламент брокера | pgvector |
| Хранилище | снимки портфеля, расчёты, история рекомендаций | PostgreSQL |
| Планировщик | ежедневный пересчёт и пересчёт по событию: сделка, купон, движение цены | cron / очередь |
| Интерфейс | карточка рекомендации, чат, кнопка «Исполнить» | веб-чат или Telegram-бот в MVP, Т-Инвестиции в пилоте |

## Поток данных

```
Планировщик ──► Агент ──► T-Invest MCP: портфель, операции, справочник
                  │
                  ├──► Налоговый движок ──► кандидаты
                  ├──► Подбор аналогов (по каждому кандидату)
                  ├──► Оптимизатор ──► план сделок
                  └──► Объяснение ──► клиент
                                        │ подтверждает
                                        ▼
                         T-Invest MCP: заявки ──► пересчёт налога
```

## Что нужно из T-Invest MCP

Адаптер: `taxharvest/sources.py`, класс `TInvestMcpSource`. В скобках указаны
сервисы T-Invest API, которые оборачивает MCP. Точные имена MCP-инструментов
сверим с документацией на этапе CONTEXT LOADED.

| Данные | Источник | Частота |
|---|---|---|
| Счета и тип счёта (брокерский / ИИС) | UsersService.GetAccounts | при подключении |
| Статус квалинвестора | UsersService.GetInfo | раз в сутки |
| Позиции, средняя цена, текущая цена | OperationsService.GetPortfolio | ежедневно и по событию |
| Сделки, купоны, дивиденды, комиссии, удержанный налог | OperationsService.GetOperationsByCursor | раз в сутки |
| Справочник облигаций и акций, уровень риска, флаг «для квалов» | InstrumentsService.Bonds / Shares | раз в сутки |
| График купонов | InstrumentsService.GetBondCoupons | раз в сутки |
| Цены, стакан (спред) | MarketDataService.GetLastPrices / GetOrderBook | онлайн |
| Заявки (после подтверждения клиента) | OrdersService.PostOrder | по действию |

## Инструменты агента

| Инструмент | Назначение |
|---|---|
| `get_tax_state` | финрез с начала года, НДФЛ, сколько брокер ещё удержит, предельная ставка |
| `get_portfolio_profile` | позиции и характеристики портфеля для вывода стратегии клиента |
| `list_candidates` | позиции с убытком и позиции, которые трогать нельзя (с причиной) |
| `find_analogs` | до 3 аналогов бумаги, доступных клиенту |
| `build_plan` | оптимальный план сделок; `exclude` — бумаги, которые агент отбраковал |

## Безопасность

* В MVP токен T-Invest только на чтение, заявки не исполняются.
* В пилоте заявки исполняются только после явного подтверждения клиента.
* LLM не получает персональных данных, кроме портфеля. Числа в ответе
  берутся только из результатов инструментов.
